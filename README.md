# ☕ Preamss Cafe

A modern and responsive café landing page designed to provide a clean and engaging online presence for a coffee shop. The website features a coffee-themed hero section, responsive navigation, mobile menu, call-to-action button, and modern typography.

## ✨ Features

* ☕ Modern coffee shop landing page
* 📱 Fully responsive layout
* 🍔 Responsive hamburger navigation menu
* 🖼️ Coffee-themed hero background
* 🎨 Clean and modern user interface
* 🔤 Google Fonts integration
* 🔘 Google Material Symbols icons
* 🛒 Order Now call-to-action
* 🌐 Cross-device friendly design
* ⚡ Lightweight and fast static website

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* Google Fonts
* Google Material Symbols

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/preamshah/cafe.git
```

### 2. Open the project

```bash
cd cafe
```

### 3. Run the website

Open `index.html` directly in your browser.

You can also use the **Live Server** extension in Visual Studio Code for local development.

## 📱 Responsive Design

The website is designed to work across:

* Desktop computers
* Laptops
* Tablets
* Mobile phones

On smaller screens, the desktop navigation automatically changes to a mobile hamburger menu.
